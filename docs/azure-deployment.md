# Azure Deployment Guide

This project is prepared for Azure App Service on Linux with Azure Database for MySQL Flexible Server.

## What Codex Prepared

- `default` - Nginx configuration for Azure App Service Linux so Laravel serves from `/public`.
- `.env.azure.example` - production environment variable checklist.
- `docs/azure-deployment.md` - this deployment guide.

## Recommended Azure Services

- App hosting: Azure App Service, Linux, PHP 8.2 or PHP 8.3.
- Database: Azure Database for MySQL Flexible Server.
- Deployment: GitHub Deployment Center or GitHub Actions generated by Azure.

## 1. Prepare GitHub

Push this Laravel project to GitHub.

Do not upload secret files:

```text
.env
vendor/
node_modules/
```

These are already covered by `.gitignore`.

## 2. Create Azure App Service

In Azure Portal:

1. Create an App Service.
2. Choose Linux.
3. Runtime stack: PHP 8.2 or PHP 8.3.
4. Choose a region near your users.
5. Create or select an App Service Plan.

Your site URL will look like:

```text
https://your-app-name.azurewebsites.net
```

## 3. Create Azure MySQL

Create Azure Database for MySQL Flexible Server.

Suggested database name:

```text
mental_health_chatbox
```

Make sure the App Service can connect to the MySQL server. If Azure creates private networking, run migrations from App Service SSH.

## 4. Configure App Service Startup Command

Azure App Service Linux needs Laravel to serve from the `public` folder.

Go to:

```text
App Service > Settings > Configuration > General settings > Startup Command
```

Set this startup command:

```bash
cp /home/site/wwwroot/default /etc/nginx/sites-available/default && service nginx reload
```

The `default` file in the project root is the Nginx config used by that command.

## 5. Configure Environment Variables

Go to:

```text
App Service > Settings > Environment variables
```

Add the values from `.env.azure.example`.

Generate an app key locally:

```bash
php artisan key:generate --show
```

Paste the result into Azure as:

```text
APP_KEY=base64:...
```

Important production values:

```text
APP_ENV=production
APP_DEBUG=false
APP_URL=https://your-app-name.azurewebsites.net
DB_CONNECTION=mysql
DB_HOST=your-mysql-server.mysql.database.azure.com
DB_DATABASE=mental_health_chatbox
DB_USERNAME=your_mysql_username
DB_PASSWORD=your_mysql_password
DEEPSEEK_API_KEY=your_deepseek_key
GOOGLE_CLIENT_ID=your_google_client_id
GOOGLE_CLIENT_SECRET=your_google_client_secret
GOOGLE_REDIRECT_URI=https://your-app-name.azurewebsites.net/auth/google/callback
```

Do not put production secrets inside `.env` before pushing to GitHub.

## 6. Deploy From GitHub

In Azure Portal:

```text
App Service > Deployment Center
```

Choose:

- Source: GitHub
- Repository: your project repository
- Branch: main

Azure can generate the deployment workflow for you.

## 7. Run Laravel Production Commands

After deployment, open:

```text
App Service > Development Tools > SSH
```

Run:

```bash
cd /home/site/wwwroot
php artisan migrate --force
php artisan storage:link
php artisan config:cache
php artisan route:cache
php artisan view:cache
```

If your dashboard needs default admin or counselling service seed data, run:

```bash
php artisan db:seed --force
```

## 8. Update Google OAuth

In Google Cloud Console, open your OAuth client.

Add Authorized JavaScript origin:

```text
https://your-app-name.azurewebsites.net
```

Add Authorized redirect URI:

```text
https://your-app-name.azurewebsites.net/auth/google/callback
```

## Troubleshooting

If the homepage shows a 404 Nginx page:

- Check the App Service startup command.
- Confirm the `default` file exists in `/home/site/wwwroot/default`.
- Restart the App Service.

If database connection fails:

- Check `DB_HOST`, `DB_DATABASE`, `DB_USERNAME`, and `DB_PASSWORD`.
- Check MySQL firewall/networking.
- Run migrations from App Service SSH.

If Google Sign-In fails:

- Check `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`, and `GOOGLE_REDIRECT_URI`.
- Confirm the same redirect URI is added in Google Cloud Console.

If assets look missing:

- Confirm deployment ran `npm run build`.
- Confirm `/public/build` exists after deployment.
